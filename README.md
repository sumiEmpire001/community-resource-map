# Community Resource Map

A responsive, accessible community service directory built with HTML, CSS and vanilla JavaScript. Search by name, area, description or category; filter by service category and wheelchair accessibility.

## Run

Open `index.html` using a local static HTTP server, e.g. `python -m http.server 8000`, then visit http://localhost:8000. The application uses ES modules, so a local server is recommended.

## Test

Requires Node.js 18 or newer. Run `npm test`. GitHub Actions runs the six built-in Node tests.

## Data and privacy

All six resources are **fictional demonstration listings** with example.org links. Replace `directory.js` with verified community providers before real-world use. No server or account is required, and search terms are not uploaded.
